Política de privacidade — shelfy

Última atualização: 25 de setembro de 2026

Resumo

  • A shelfy não coleta, não vende e não compartilha dados de usuários do Google.
  • Este site não tem login, não usa cookies, não usa analytics e não tem rastreamento de terceiros.
  • A busca por código acontece no seu navegador. O código digitado não é enviado a servidor nenhum.

1. Quem somos

A shelfy é um projeto pessoal de Carlos Eduardo. Ela publica nas redes sociais posts com produtos de uma loja online, e este site é o link da bio da shelfy: a página onde qualquer pessoa digita o código de um post e encontra o link do produto.

Esta política vale para a shelfy e para este site.

2. Dados de serviços do Google

A shelfy não coleta, não vende e não compartilha dados de usuários do Google com ninguém. O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

3. Este site: a busca por código

  • Sem login e sem cadastro. Qualquer pessoa usa a busca sem criar conta e sem informar nada sobre si.
  • Sem coleta de dados pessoais. A shelfy não pede, não coleta e não guarda dados pessoais de quem visita.
  • Sem cookies, sem analytics, sem rastreamento de terceiros. Não há pixels, estatísticas de visita, anúncios nem scripts, fontes ou imagens carregados de outros sites.
  • A busca acontece no seu navegador. Ao abrir a página, o navegador baixa o catálogo público da shelfy (um arquivo estático com código, título e link de cada produto, hospedado junto com o site) e procura o código ali mesmo. O código que você digita não é enviado a servidor nenhum.
  • Últimos códigos buscados. Para você voltar a um produto com um toque, o site pode lembrar os 3 últimos códigos encontrados. Eles ficam guardados só no seu aparelho (no armazenamento local do navegador), nunca são enviados a lugar nenhum, e você pode apagá-los no botão “Limpar” da página inicial ou limpando os dados do site no navegador.

4. Links de compra e links de afiliado

O botão “Ver produto” leva a sites de terceiros (as lojas), que têm políticas de privacidade e termos próprios. O que acontece nesses sites (cookies, cadastro, compra, pagamento, entrega) é responsabilidade deles.

Os links de produto são links de afiliado: se você comprar por eles, a shelfy pode receber uma comissão, sem nenhum custo extra pra você.

A shelfy não envia à loja nenhuma informação sobre você nem sobre a sua busca: os links abrem sem informar de qual página você veio.

5. Alterações desta política

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização revisada no topo.
