Política de privacidade — shelfy

Última atualização: 24 de setembro de 2026

Resumo

  • O shelfy acessa o Google Drive apenas com a permissão drive.file: só enxerga os arquivos e pastas que ele mesmo criou.
  • Nenhum dado do Google é compartilhado, vendido ou enviado a terceiros.
  • Este site não tem login, não usa cookies, não usa analytics e não tem rastreamento de terceiros.
  • A busca por código acontece no seu navegador. O código digitado não é enviado a servidor nenhum.

1. Quem somos

O shelfy é um projeto pessoal, mantido por uma única pessoa (o “dono do projeto”). Ele gera automaticamente imagens e vídeos de produtos de uma loja online e publica esses conteúdos nas redes sociais. Este site é o link da bio do shelfy: a página onde qualquer pessoa digita o código de um post e encontra o link do produto.

Esta política vale para as duas partes do shelfy: a ferramenta que usa o Google Drive e este site público.

2. A ferramenta shelfy e o Google Drive

O shelfy acessa o Google Drive apenas com a permissão drive.file, ou seja, só enxerga os arquivos e pastas que ele mesmo criou. Não lê, não altera e não apaga nenhum outro arquivo do Drive.

O Drive é usado só para guardar as imagens e os vídeos que a própria ferramenta gera. A única conta de Google usada é a do dono do projeto, e os arquivos enviados ficam só no Drive do dono da conta.

Nenhum dado do Google é compartilhado, vendido ou enviado a terceiros. Os dados do Google também não são usados para publicidade. O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

3. Este site: a busca por código

  • Sem login e sem cadastro. Qualquer pessoa usa a busca sem criar conta e sem informar nada sobre si.
  • Sem coleta de dados pessoais. O site não pede, não recebe e não guarda dados pessoais de quem visita.
  • Sem cookies, sem analytics, sem rastreamento de terceiros. Não há pixels, estatísticas de visita, anúncios nem scripts, fontes ou imagens carregados de outros sites.
  • A busca acontece no seu navegador. Ao abrir a página, o navegador baixa o catálogo público do shelfy (um arquivo estático com código, título e link de cada produto, hospedado junto com o site) e procura o código ali mesmo. O código que você digita não é enviado a servidor nenhum.
  • Últimos códigos buscados. Para você voltar a um produto com um toque, o site pode lembrar os 3 últimos códigos encontrados. Eles ficam guardados só no seu aparelho (no armazenamento local do navegador), nunca são enviados a lugar nenhum, e você pode apagá-los no botão “Limpar” da página inicial ou limpando os dados do site no navegador.
  • Hospedagem. O site é hospedado no GitHub Pages. Como acontece com qualquer servidor web, o serviço de hospedagem pode registrar dados técnicos das conexões (como o endereço IP) para segurança e funcionamento. O shelfy não tem acesso a esses registros e não os usa.

4. Links de compra e links de afiliado

O botão “Ver produto” leva a sites de terceiros (as lojas), que têm políticas de privacidade e termos próprios. O que acontece nesses sites (cookies, cadastro, compra, pagamento, entrega) é responsabilidade deles.

Os links de produto são links de afiliado: se você comprar por eles, o shelfy pode receber uma comissão, sem nenhum custo extra pra você.

O shelfy não envia à loja nenhuma informação sobre você nem sobre a sua busca: os links abrem sem informar de qual página você veio.

5. Alterações desta política

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização revisada no topo.
